# Agent Workshop

This is a basic workshop setup.

Usage

```console
./workshop.sh --work /path/to/project/repo
workshop shell
```

The workshop contains several Agent frameworks, i.e.,

- omp
- copilot
- opencode

And other tools such as

- gh
- neovim

Host configurations are mounted on the workshop so that the agents do not have to be authenticated if they are already on the host.
